### Quindro is an open-source, AI-first code editor built for developers.

Use AI agents on your codebase, checkpoint and visualize changes, and bring any model or host locally. Quindro sends messages directly to providers without retaining your data.

This repo contains the full source code for Quindro's Desktop app. If you're new, welcome!

---

### Key Features
- **Full Agentic Coding**: Autonomous agents that can plan, edit, run tests, and debug across multiple files.
- **Sidecar & Modern Visualizations**: Interactive workspaces, beautiful dark UI, streamlined sidebar, and intelligent diff views.
- **Provider Choice**: Connect to Claude, OpenAI, Gemini, Ollama, DeepSeek, or any custom API.
- **Privacy First**: Direct API calls from your machine to your chosen model provider. No middlemen, no tracking.
